# Demo Player · Gestione Turni (Nicora Case Study)

Landing page responsive e ultra-leggera per la presentazione video della piattaforma gestione turni retail / garden center sviluppata da Davide Braghiroli.

## Funzionalità
- Riconoscimento automatico dell'orientamento dello schermo (`portrait` vs `landscape`)
- Switch dinamico del formato video:
  - **Smartphone Verticale**: riproduce `brag-vertical.mp4` (9:16) a tutto schermo
  - **Desktop / Tablet Orizzontale**: riproduce `brag.mp4` (16:9) con mockup desktop
- Riproduzione fluida con poster frame 0 istantaneo
- Pulsante audio overlay per conformità autoplay mobile
- Call to action integrate (WhatsApp + Email)

## Rilascio Vercel
Questa repository si sincronizza automaticamente con Vercel a ogni push sul branch `main`.
